# WinMirroring: справочник по функциям

Что умеет приложение и где это в коде. Составлен по коду версии 1.0.75 (ноябрь 2026), разделы о микрофоне, перелистывании мониторов и исправлениях обновлены под 1.0.76 и 1.0.77: каждый раздел написан после чтения соответствующих файлов целиком, не по памяти и не по README. Все упомянутые в разделах пути и идентификаторы сверены с репозиторием автоматически, выборка констант — вручную; поведение запуском не проверялось, если в разделе не сказано иное.

Три документа делят работу так:

- `README.md` — для пользователя: как поставить и как пользоваться.
- `docs/ARCHITECTURE.md` — почему сделано так: решения и заметки по выпускам в порядке появления. Ранние его части местами устарели (см. «Расхождения» ниже).
- `docs/FEATURES.md` и `docs/features/*.md` — что есть сейчас: каждая функция, её механизм, настройки, сообщения, ограничения и тесты. **Источник правды — код; если справочник с ним расходится, прав код, а справочник надо поправить.**

**Правило сопровождения.** Изменение, которое добавляет, убирает или меняет функцию, настройку, сообщение протокола, жест или кнопку, правит соответствующий файл в `docs/features/` в том же коммите. Перед работой над областью сначала читается её файл — он короче кода и говорит, что там уже есть.

## Расхождения и находки

Собрано при составлении справочника. Это не список задач: решать, что из этого чинить, — отдельно.

### Что исправлено по этому списку

В 1.0.76: «только видимая часть» на HEVC; пустой вид после отступления с HEVC на H.264; откат ручных адресов кнопкой «Применить»; масштаб при смене монитора из панели.

В 1.0.77:
- окно просмотра — щипок и свайп тремя пальцами без управления (06);
- экран — закрытый вид отдаёт таймер 1 мс и ключи; смена монитора не теряет ограничение кадров на батарее; поток на плитках не отчитывается как UDP; запрет просмотра и запрет управления действуют на уже открытые виды (04, 05);
- приложение — переключатель автообновления без перезапуска, установка отложенного обновления как только устройство освободилось, проверка результата установки и SHA-256 архива, уборка старых архивов; запросы на возобновление вида растянуты на полторы минуты; число вне диапазона в настройках становится ближайшим допустимым (07, 08);
- ядро — устройство без сессии, переставшее объявлять себя, становится `Offline`; знакомство по цепочке не теряет только что созданное сопряжение; нечитаемый `settings.json` сохраняется рядом под именем с датой и попадает в журнал; сообщение больше 16 МБ отвергает отправитель, а не обрыв сессии у получателя (01);
- удалённая консоль — длинная строка вывода приходит целиком; `exit N` возвращает свой код, а консоль, закрывшаяся без кода, даёт 67 вместо «отказа» 65; слишком длинный сценарий не выполняется по частям; исправлена испорченная кодировка сообщения помощника; выключение разрешения закрывает открытые консоли; `wm-cli` с пустой командой или нечитаемым файлом — ошибка использования (09);
- буфер обмена и файлы — брошенная вставка заканчивается сама и гасит индикатор; опоздавшее содержимое не ложится поверх более нового; отправитель узнаёт о любом отказе принять файлы и об обрыве связи сразу; данные сверх объявленного размера файла останавливают передачу; загрузка для прямой вставки отменяется с закрытием сессии (03);
- выпуск — CI сверяет тег с версией (09).

### Что осталось

- **Список устройств.** Чужое несопряжённое устройство, увиденное однажды, из списка не убирается (теперь оно `Offline`, но остаётся): убрать его — значит потерять его место в общей раскладке у всех устройств при следующем сохранении, это решение о поведении, а не правка (01).
- **Приоритет трафика.** Звук и видео экрана идут одним UDP-сокетом и потому одним потоком QoS (класс «голос»); поставить звук впереди можно только вторым сокетом. Комментарии приведены в соответствие, механизм не менялся (01).
- **Знакомство по цепочке.** `vouch-relay` отправляется один раз: если у посредника нет сессии с дальним устройством, доверие остаётся односторонним, пока кто-то не сопряжёт их подтверждением (01).
- **`ScaleBitrate`** не поднимает битрейт выше заданного для картинки больше 1080p — это не ошибка, а смысл настройки «битрейт», но 1440p и 4K при том же числе выглядят хуже (04).
- **`Input.Enabled = false`** выключает только роль управляющего; запрета «не принимать ввод с других устройств» в настройках нет (02).
- **Испорченный `settings.json`**: файл теперь сохраняется, но устройство всё равно запускается как новое, и кроме журнала об этом ничто не говорит (01).
- **Удалённая консоль**: старый `wm-cli` с новой программой всё ещё может зависнуть на `-c ""`; выключение команд администратора завершает и помощника, так что следующее включение снова спросит UAC (09).
- **Буфер обмена**: брошенная вставка считается брошенной через 2 минуты без чтения (15 с, если предложение уже ушло из буфера) — кто дольше думает над вопросом Проводника «заменить файл?», получит «передача не удалась» и новую передачу при продолжении; `LastWriteUtcTicks` из чужого манифеста не проверяется на диапазон (03).
- **Автообновление**: отложенный архив не переживает перезапуск; подписи кода нет (07).
- **Выпуск**: CI не запускает тесты; `wm-cli` в архив выпуска не входит (09).
- **Не проверено на устройствах** из исправленного: жесты без управления, вставка файлов через Проводник после правок предзагрузки, обновление целиком с проверкой SHA-256.

### Где документы отстали от кода

- **README: «по умолчанию не больше 30 кадров/с».** `ScreenSettings.MaxFps` по умолчанию 60; 30 — это `PowerSettings.Fps` в режиме экономии.
- README и ARCHITECTURE называют запуск помощника администратора без запроса UAC «следующим шагом» — он есть (`ElevatedHelperTask`, кнопки «Выдать права один раз» / «Спрашивать права снова»).
- README описывает вкладки старого `MainWindow` и окно просмотра «с рамкой, F11 — во весь экран». Сейчас «Параметры» — вкладка React-окна, а окно просмотра открывается сразу во весь экран, F11 выводит в режим с рамкой. Кнопка «☰ Меню» сверху по центру в полном экране не показывается.
- README: поле набора «можно набрать руками и отправить целиком» — по коду набранное тоже уходит через 1,3 с паузы.
- README ничего не говорит об автообновлении с GitHub, разрешениях удалённой консоли, режиме экономии, `wm-cli --exec`.
- ARCHITECTURE §4–5: `ScreenCapabilityMessage` (на деле `DeviceCapabilitiesMessage`), «TLS 1.3» (версию выбирает ОС), отдельное соединение на файл (на деле канал `File` той же сессии), проект `WinMirroring.Files` (нет), «курсор рисует WGC» (указатель передаётся отдельно), окно из двух неподтверждённых кадров (три), Raw Input как источник движения мыши (только для упора в край), сетка как движок раскладки (свободное поле), перо через `InjectSyntheticPointerInput` (такого кода нет), настраиваемые горячие клавиши (есть только Ctrl+Alt+Home), «40 тестов».
- В комментариях кода осталось «PIN pairing» (PIN нет, есть «Принять» и шестизначный код для сверки); XML-комментарий `ScreenCodec` описывает старую раскладку кадров.

### Настройки, которых нет в интерфейсе

`AppSettings.PinConnectionsToInterface`, `AppSettings.FindPeersOnTailscale`, `AudioSettings.FollowScreenViewer` — только в файле настроек. В «Параметры → Сеть → Адреса вручную» адрес можно добавить, но убрать — только из лотка на странице устройств.

### Чего нет вовсе

Пера как пера (приходит как мышь), работы на экране блокировки и на защищённом рабочем столе UAC, выбора устройства для системного звука и выбора микрофона, истории буфера обмена, PTY в удалённой консоли (это не терминал: нет ввода в работающую программу и изменения размера).
